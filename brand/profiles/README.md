# Profiles

One file for each profile that has more to it than a bio: the words, the settings and the images, so each one can be rebuilt from here and there's a record of what's live. The sites themselves don't keep history, so this folder does.

| Profile | File |
| --- | --- |
| LinkedIn | [linkedin.md](linkedin.md) |
| GitHub Sponsors | [github-sponsors.md](github-sponsors.md) |

The bios in [bios.md](../bios.md) are still the source for anything shorter. A profile file only holds what's unique to that site.

## Adding one

When a new profile needs the same care, give it a file here with these sections, leaving out any that don't apply:

1. **What it's for**, in a line or two, and what stays off it.
2. **Settings**, as a table of setting and value.
3. **Words**, each in a quote block so it can be copied straight across.
4. **Images**, pointing at files in this kit rather than copies.
5. **Changing it**, if there's anything else to keep in step.

Then add it to the table above.
