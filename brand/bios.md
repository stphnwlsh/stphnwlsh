# Bios

One set of words in four lengths, so every profile says the same thing at the right size. Change them here first, then copy them out. The short bio also lives in [tokens/tokens.json](tokens/tokens.json) as `person.bio.short` for anything that builds from the tokens.

| Length | Where it goes |
| --- | --- |
| Tagline | Banners, the website hero, the X and Bluesky display line |
| Short | GitHub bio, Medium, X, Bluesky, Instagram, anywhere with a character limit (it's 151) |
| Medium | The profile README intro, conference blurbs |
| Long | The website's About, speaker pages, anywhere that asks for a full bio |
| Why I grow a mo | Only where Movember is the topic: the website in November, the README's Movember line, the Movember page |

LinkedIn's About and the GitHub Sponsors page say more than a bio, so their words live in [profiles/](profiles/README.md).

The day job gets one sentence in the medium and long bios, so recruiters can see where I am without the page turning into a CV. The full work story stays on LinkedIn. "Fewer layers than an onion, more than a sandwich" belongs to the Lean Mean Clean Apps section on the website and the README, so it stays out of the bios.
